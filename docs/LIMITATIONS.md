| VeeR EL2 | all / config | PMP can't be switched off. `veer.config` accepts `pmp_entries=0`, but the RTL declares `[pt.PMP_ENTRIES]`-sized unpacked arrays (`el2_veer.sv:835`, `el2_pmp.sv:41`, `el2_dec_pmp_ctl.sv:58`, `el2_dec_tlu_ctl.sv:269`, `el2_dec.sv:297`), which don't elaborate at 0 ("value must be positive"). So VeeR carries 16 PMP entries that Hazard3 and Ibex don't have. | yosys-slang elaboration log with `pmp_entries=0` (reproduce: set it in `cores/veer_el2/gen_config.sh`) | `pmp_entries=0`; fell back to the RTL minimum, 16 | Report as-is with this note, or write a patch that sizes the arrays as max(1, N) and ties PMP off (about 5 files), if the professor wants a PMP-free comparison |
| VeeR EL2 | all / config | The debug module (`el2_dbg`) is inside `el2_veer` and has no config switch. We drop only the JTAG TAP/DMI wrapper (we synthesize `el2_veer`, not `el2_veer_wrapper`).
